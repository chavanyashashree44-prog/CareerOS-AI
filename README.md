# CareerOS AI 🚀
### AI-Powered Career Intelligence Platform

CareerOS AI is an intelligent career development platform designed to help students and job seekers prepare for their careers through AI-powered tools.

## 🌐 Project Links

- **GitHub Repository:** https://github.com/chavanyashashree44-prog/CareerOS-AI
- **Live Demo:** Deployment in progress

## ✨ Features

- AI-powered resume analysis
- Resume builder
- AI interview practice with feedback and evaluation
- Interview question bank for multiple developer roles
- Speech-to-text support for interview practice
- Career profile and skill development
- Job and career opportunity tracking
- User authentication and saved interview history

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- React Router
- Supabase
- CSS

### Backend
- Node.js
- Express.js
- Google Gemini API

## ⚙️ Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/chavanyashashree44-prog/CareerOS-AI.git
cd CareerOS-AI
```

### 2. Start the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Start the backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

## 🔐 Environment Variables

Create `.env` files inside both `client` and `server` folders.

Do not upload API keys, passwords, or secret environment variables to GitHub.
